Управление портфолио
На сайт

1. Подключение GitHub

Вставь Fine-grained Personal Access Token с доступом Contents: Read and write к репозиторию rainoff3/Nikshmakov-portfolio.

Токен используется только в памяти этой вкладки: он не записывается в файлы сайта, localStorage или cookies. Не отправляй его никому и закрывай вкладку после работы.

2. Новое видео

Обложка автоматически уменьшается до подходящего размера и загружается в папку previews.

3. Опубликованные видео

Здесь можно удалить ролик с сайта. Файл обложки в GitHub также будет удалён, если он больше не используется.

Публикация создаёт коммиты в GitHub. Обычно сайт обновляется через 1–3 минуты после завершения GitHub Pages build.
